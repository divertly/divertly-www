# DIVERT.LY 

This repository is the code for Divertly's public marketing website, `divert.ly` . 

Use the files in _context to understand the company, positioning, etc. and for the website copy.

## Architecture

This is a static website, as such, it should minimaly rely on frameworks or excessive javascript. Prefer vanilla JS over opinionated or framework javascript.

The website will be deployed on Cloudflare R2 to be served statically.


## Design

The `images` directory has four subdirectories:
- branding -- branding assets for Divertly
- favicons -- favicons
- screenshots -- screenshot of the app dashboard with a Safari browser frame
- team -- cartoon headshots for the founding team, Ben and Pete.

You should take inspiration from websites like:
- Tailscale.com
- Vantage.sh
- Vercel.com
- Featherless
- Ramp.com
- Vanta.com
- Resend.com

Use Bootstrap Icons for icons.
Bulma or Tailwind for CSS.

Divertly's "brand color" is 0,196,167 (RGB) or #00c4a7 (HEX)

## Constraints

- There should be links to `legal.html`.
- The website should comply with ADA regulations and be accessible, with considerations for screen readers and like.
