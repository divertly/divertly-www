# Design history

- **Baseline 1** (`baseline-1/`): the original cool, mono-flavored look ported from the old landing page. Archived with its CSS, layout, partials, and screenshots.
- **Baseline 2** (current): "Soft". White page, soft shadows and rounded cards, green-to-blue gradient accents, Cal Sans display type with Inter for text and Plex Mono for code. It lives in `dist/css/site.css` (the section headed "Design: Soft") and the shared layout and partials in `src/`.

To go back to Baseline 1, follow `baseline-1/DESIGN.md`. Page-specific CSS for the Founder's Circle was rewritten for Baseline 2 (`src/pages/circle.head.html`), so use git history if you need its old version.
