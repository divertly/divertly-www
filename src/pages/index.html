# Send 10% of go.acme.dev/launch to a canary
curl -X POST https://api.divert.ly/v1/domains/$DOMAIN_ID/routes/$ROUTE_ID/targets \
  -H "Authorization: Key $DIVERTLY_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "url": "https://app.acme.dev/v3-canary",
    "weight": 10
  }'

// Ramp it to 50%, or roll it back to 0, with one more call. No redeploy.

For developers

Everything the dashboard does, the API does.

Create routes, add targets, and change weights from code. It's plain HTTP, so it works with curl today. Official SDKs for Go, Python, and JavaScript are coming soon.

# 1. Create a weighted route on a domain you've added
curl -X POST https://api.divert.ly/v1/domains/$DOMAIN_ID/routes \
  -H "Authorization: Key $DIVERTLY_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "nickname": "Launch",
    "slug": "launch",
    "targetStrategy": "weighted"
  }'

// Create a route at go.acme.dev/launch, then change where it sends people with a PUT.

Questions

What engineers ask first.

Is it reliable?

We strive to maintain a reliability SLO of 99.8% or better, but don't take our word for it. View our historic reliability data on our status page.

Why not just build this on Cloudflare Workers or nginx?

You can. The redirect is the easy part. The work is everything around it: SSL provisioning, custom-domain handling, abuse and phishing mitigation, analytics, uptime, and the multi-target selection logic. Divertly is that infrastructure, so you don't maintain it.

Do I have to move my DNS to you?

No. Point a CNAME at us and keep DNS where it is. Full nameserver delegation is coming soon.

How am I billed?

On clicks served, not on how many links you create. See pricing.

Can I export my data?

Yes. We'll export your data on request. Contact support to request an export.
